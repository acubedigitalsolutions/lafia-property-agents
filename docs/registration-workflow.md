# Agent Registration Workflow

## Overview

This document describes the complete registration and approval process for property agents.

---

## Step 1: Account Creation

The agent provides:

- Full Name
- Phone Number
- Email Address
- Password

The system creates an account with the role "Agent".

Status:
- Account: Active
- Agent Profile: Incomplete

---
### Registration Progress

The system tracks the agent's progress through the following stages:

1. Account Created
2. Profile Incomplete
3. Profile Submitted
4. Pending Review
5. Approved – Payment Required
6. Active Member
7. Membership Expired

## Step 2: Complete Profile

The agent completes their professional profile by providing:

- Profile Photo
- Government ID
- Office Address
- Years of Experience
- Bio
- Areas of Operation

The system validates that all required information is provided.

Status:
Profile Submitted

---

## Step 3: Administrator Review

The administrator reviews:

- Government ID
- Contact Information
- Profile Details

Decision options:

- Approve
- Reject
- Request More Information

---

## Step 4: Membership Payment

If approved:

The system notifies the agent to pay the annual membership fee.

After successful payment:

- Membership Status = Active
- Membership Expiry = One year from payment date

---

## Step 5: Membership Issued

The system automatically generates:

- Membership ID (Example: LPA-0001)
- Verified Badge
- Digital Membership Card
- Membership Certificate
- Public Agent Profile

---

## Step 6: Public Listing

The agent now appears in:

- Search Results
- Featured Agents
- Membership Verification

---

## Step 7: Renewal

Thirty days before expiry:

The system sends a renewal reminder.

If payment is received:

- Membership Expiry is extended by one year.

If payment is not received:

- Membership Status = Expired
- Profile is hidden from public search.
