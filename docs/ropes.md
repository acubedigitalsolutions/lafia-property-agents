# User Roles

## Overview

The Lafia Property Agents platform has three main user roles.

---

## 1. Visitor

Visitors do not need an account.

They can:

- Search for verified property agents.
- View agent profiles.
- Verify an agent's membership.
- Submit property requests.
- Report an agent.
- Read News & Tips.
- Contact agents.

Visitors cannot:

- Register agents.
- Approve memberships.
- Access the admin dashboard.

---

## 2. Property Agent

Registered property agents can:

- Create an account.
- Log in.
- Complete their profile.
- Upload a government-issued ID.
- Upload a profile photo.
- View their membership status.
- Renew their annual membership.
- Download their membership card.
- Download their membership certificate.
- Update their profile.

Agents cannot:

- Approve other agents.
- Access administrator features.

---

## 3. Administrator

Administrators can:

- Approve or reject registrations.
- Suspend or reactivate agents.
- Manage subscriptions.
- Manage locations.
- Publish News & Tips.
- Review complaints.
- View property requests.
- Manage platform settings.
- View reports and statistics.
