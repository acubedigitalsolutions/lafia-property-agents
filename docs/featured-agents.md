# Featured Agents

## Overview

Featured Agents receive additional visibility on the platform.

This is an optional promotional service.

It is NOT part of the annual membership.

---

## Benefits

Appear at the top of search results.

Appear on the Home Page.

Receive a Featured Badge.

Receive higher visibility.

---

## Badge

🌟 Featured Agent

---

## Administrator Controls

Approve Featured Agent.

Set start date.

Set expiry date.

Remove Featured status.
