# Lafia Property Agents

**A Service of A-Cube Digital Solutions**

## Connecting You to Verified Property Professionals

Lafia Property Agents is a trusted online platform that connects property buyers, tenants, landlords, landowners, and investors with verified housing and land property agents in Lafia, Nasarawa State, Nigeria.

## Vision

To become the most trusted property agent directory in Nigeria.

## Mission

To promote professionalism, transparency, and trust in property transactions through a secure, verified membership platform.

## Features

- Verified Agent Registration
- Government ID Verification
- Annual Membership Subscription
- Agent Search by Location
- Membership Verification
- Property Requests
- Report an Agent
- News & Tips
- Digital Membership Card
- Membership Certificate
- Admin Dashboard
- Paystack Payment Integration

## Technology Stack

- Frontend: Next.js
- Backend: Laravel
- Database: MySQL
- Payment: Paystack
